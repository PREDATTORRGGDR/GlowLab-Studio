# GlowLab Studio

Делает вертикальный ролик 1080x1920 для Shorts, Reels и TikTok в одно нажатие:

1. **Начало:** кусок твоего эдита со знаменитостью, при желании с текстом поверх.
2. **Разбор лица:** звезда из каталога (гармония) или твой анализ GlowLab (полный разбор). Диктор ElevenLabs, на экране фото с точками разметки, метрики и баллы.
3. **Сборка:** сценарий пишется автоматически, озвучка и монтаж через ffmpeg, на выходе `projects\<имя>\final.mp4`.

## Требования

Windows 11, Python 3.11+, ffmpeg и ffprobe (в PATH или в папке `bin\`), десктопное приложение Claude с подпиской, Microsoft Edge (кадры ролика это скриншоты твоего Mini App, он открывается в скрытом Edge только на чтение).

## Как пользоваться

1. Выбери, кого разбираем: звезду из каталога (все 449, поиск по имени) или «Мой анализ» (последний анализ из GlowLab, кнопка «Обновить из GlowLab»).
2. Выбери эдит (или «+ Добавить», или перетащи видео прямо в окно: оно сразу появится в списке). Крестик на плитке убирает эдит в Корзину Windows. Кнопка «Таймлайн» (или клик по выбранному эдиту) открывает плеер: перетащи жёлтый отрезок туда, откуда эдит пойдёт в начало ролика, край отрезка меняет длину, «Проиграть отрезок» крутит выбранный кусок. По умолчанию первые 5 секунд, выбор запоминается для каждого эдита. Подпись поверх это вопрос «Насколько привлекателен …?».
3. Нажми «Сделать ролик». Около 1.5 минут: сценарий, съёмка экранов Mini App, голос, монтаж. Звук эдита идёт музыкой на повторе и тише под голосом.
4. Готовый ролик в плеере и в `projects\<имя-дата>\final.mp4`. Под ним хэштеги для TikTok с кнопкой «Скопировать».
5. TikTok: кнопка «Выложить в TikTok» открывает TikTok Studio справа от GlowLab и вставляет эти хэштеги в описание. Видео в TikTok загружаешь и публикуешь сам, приложение ничего не публикует. Вход в TikTok сохраняется в `webview_data\`, входить нужно один раз (чтобы выйти, удали эту папку). «Стоп» останавливает вставку, закрытие окна TikTok (X) только прячет его.
6. Поменять ролик: напиши Claude своими словами в «Попросить Claude» («сделай короче», «начни с плюсов», «убери про губы») и нажми Enter. Экраны Mini App доснимаются только для новых метрик, переозвучиваются только изменённые реплики. Можно и руками: поправь реплики или убери сцену и нажми «Пересобрать с правками».

В шапке видно, сколько символов осталось в ElevenLabs и примерно на сколько роликов их хватит.

## Установка и запуск

```
pip install -r requirements.txt
python app.py
```

## Куда что класть

| Что | Папка |
|---|---|
| Эдиты со знаменитостями (mp4) | `library\edits` |
| Шрифты для текста (.ttf с кириллицей; по умолчанию Oswald) | `library\fonts` |
| Фоновая музыка | `library\music` |
| ffmpeg.exe, ffprobe.exe (если их нет в PATH) | `bin\` |
| Вход в TikTok (куки окна TikTok, создаётся само) | `webview_data\` |

Готовые ролики появляются в `projects\`.

## Ключи

Всё вводится в окне «Настройки» и хранится только в `settings.json` рядом с приложением (в git не попадает). Сохранённые ключи в окне не показываются, видны только 4 последних символа.

| Поле | Зачем |
|---|---|
| Ключ ElevenLabs, голос | Озвучка. По умолчанию Nikolay: он из библиотеки ElevenLabs и через API работает только на платном тарифе; на бесплатном выбери стандартный голос |
| Модель Claude | Сценарий. Пишется через Claude Code из десктопного приложения Claude по подписке, ключ API не нужен. Один раз войди: запусти `claude.exe` из `%LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude\claude-code\<версия>\` и выполни `/login` |
| API_BASE, токен бота, Telegram id, first_name, last_name, username | Вход в GlowLab, чтобы получить твои анализы (только чтение). Имя, фамилия и username точно как в Telegram: сервер обновляет ими профиль |

## Сборка exe

```
pip install -r requirements.txt pyinstaller
build.bat
```

Появится `GlowLabStudio.exe` в корне проекта. Его нужно держать рядом с `library\`, `projects\` и `settings.json`: оттуда он берёт эдиты, ключи и туда кладёт ролики. Запуск занимает несколько секунд, exe распаковывается.
